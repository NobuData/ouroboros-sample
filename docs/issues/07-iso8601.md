## Problem

Other systems exchange durations as ISO 8601 (`PT1H30M`). There is no way to produce that
form here, so callers build it by hand.

## Acceptance criteria

- [ ] `to_iso8601(seconds)` returns the ISO 8601 form: `to_iso8601(5400) == "PT1H30M"` and `to_iso8601(45) == "PT45S"`.
- [ ] Zero is `"PT0S"`.
- [ ] A negative value raises `ValueError`, as `format_duration` does.
- [ ] `to_iso8601` is exported from the package and listed in the README.
